## 1. Project objective in human terms, not a progress counter

The original challenge: how can one standards-based CSAPI client provide useful, coherent **Resource Details for multiple unlike sensing systems**, retaining source-specific physical parts, connected equipment, interfaces, reporting, settings, status, history, power, communications and control **without becoming four vendor-hard-coded screens or reducing everything to generic raw SensorML**? Original TRSS/OmniSense motivated this research, but their full authenticated operational datasets were unavailable; four better documented controlled source situations became the bounded tests.

**Division of responsibilities:** (1) **real source + standards/donor evidence** define what is actually known; (2) the **implementation-independent DIM** represents warranted common meaning and separately preserved specialization; (3) a **separate CSAPI application Profile** proposes justified standards-native and profile-authored ways to convey meaning; (4) an integrating **native producer** publishes the correct original resource and warranted source evidence; (5) **one generic Glaux reader** discovers and presents it with original/derived/unknown status; (6) independent source fidelity and interoperability checks determine what truly survived. **Passing a local JSON parser test does not make an RFC link source-authentic, and a functioning producer/client pair both written by this project does not establish independent vendor interoperability.**

**Working boundary:** Source-grounded focal **sensing System or arrangement**, with typed, conditional relationships to distinct physical/software/functional/hosting/reporting/management participants. A manufacturer reference kind, an actual physical device and a persistent real field station do not automatically share one mandatory class root. No final overarching domain name, mandatory V1 eight-subject modules, five permanent classes, power-first agenda, physical containment tree or universal cardinality is adopted. Donor terms can qualify, falsify or replace current propositions; “chassis” is research shorthand only.
