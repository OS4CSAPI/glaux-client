## 1. Extraction rules and current scope

This register records **what the original source calls something, says it is, or says it can do**. It deliberately does **not** map claims into our proposed Domain Information Model (DIM), Open Geospatial Consortium (OGC) Application Programming Interface (API) – Connected Systems (CSAPI), or any other donor vocabulary. That happens only in later iterations.

Each **F###** is one separately citable source-level proposition, identified with an **I02 source ID**, precise Markdown/firmware line range, and frozen Git commit. The source-level labels are: **PRODUCT** (manufacturer model/specification), **DESIGN** (hardware/assembly documentation), **IMPLEMENTATION** (source-code/configuration/algorithm statement), **PLATFORM** (published API/registration semantics), and **PLATFORM / EXAMPLE** (example code with no returned data). The labels **UNIT** and **OBSERVATION** are reserved for verified individual equipment or measurements, **neither of which has been obtained**. Every F### is **SOURCE-DIRECT as a statement in the cited source**, *not independently verified as correct engineering or evidence of actual installation*. If the statement could be misread, its last column records that limitation.

Primary sources are frozen by exact SHA in [I02](I02_Versioned_Source_Corpus_Register_v0.1_27OCT2026.md). Citations use the **Chicago Manual of Style, 18th edition, author–date** convention plus a line-anchored upstream reference. The year in an author's entry identifies the *2026 frozen source snapshot*, **not a claimed publication date of each technical page**. The documentation is authored using templates; some exact part numbers in the pinned Markdown differ from separately rendered public text, and are retained as **source-claimed spellings pending I04**.

**Scope of this extraction:** 60 propositions from 17 directly pertinent pinned source files (A02, D01, D02, D03, D04, D05, D06, D07, D08, D09, D10, D11, H01, H05, H06, R01, R02). The I02 corpus has 25 registered files; we do not infer facts from the other indexed schematics, layouts, build configs, or documents that have not been substantively interpreted. **This is a fact register, not a 25-file exhaustive audit.**
