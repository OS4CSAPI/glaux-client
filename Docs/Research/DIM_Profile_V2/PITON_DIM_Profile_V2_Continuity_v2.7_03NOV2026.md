## 1. Human objective and what successful delivery must mean

The project began when the TRSS and McQ OmniSense sensing-system interfaces showed that vendor-specific presentations contain rich identity, physical equipment, capabilities, configuration, status, history, measurements and control distinctions that a generic OGC API – Connected Systems (CSAPI) resource listing will not automatically organize for an operator. The target is **one useful, consistent and source-faithful Glaux Resource Details UI**, applicable across unlike sensing systems **without hard-coded model-name renderers**, while retaining true differences and displaying missing/unsupported evidence honestly.

There are three separate products: (1) an **implementation-independent Domain Information Model (DIM)** of bounded *whole sensing systems* and their evidence-qualified relationships, rather than a rigid API resource tree; (2) a distinct **CSAPI application Profile** selecting supported original CSAPI/SensorML/SWE/OMS behavior and adding only explicit, testable, project-authored rules where justified; and (3) a **Profile-aware generic Glaux client** with source-to-display fidelity evidence and a verified native producer route. Passing unit tests for self-created fixture JSON does not mean an independently created producer/consumer can discover all those semantics.

The original provisional phrase “system and sensor and equipment” remains a working boundary; no final overarching domain name, universal superclass, mandatory eight-piece anatomy or canonical physical part-of tree has been adopted. The earlier 182 donor source artifacts are a population, **not 182 equally reviewed standards** or a vote. Fair use of later donors (SAPIENT v2, ISA, The Open Group SOSA, IEEE 1451/NIST playground, AAS, OPC UA Devices/PA-DIM, W3C Web of Things, SOSA/SSN, OMS, and others) can add, split or revise candidate meanings rather than automatically accept a V1 favorite. Project power/status research remains valid source material but does not control the V2 agenda.
