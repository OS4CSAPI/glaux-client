## 3. Strongest Phase B structural findings

The comparison found stronger convergence around semantic distinctions than around donor package/module names.

High-confidence recurring distinctions:

1. persistent subject vs reusable model/type vs digital/runtime representation;
2. physical composition vs functional grouping vs network topology vs deployment/host vs virtual/mediated relationships;
3. whole equipment vs internal sensing element/channel;
4. capability vs selected configuration vs current state vs execution vs result;
5. static description vs dynamic evidence/action;
6. property/variable meaning vs particular value/result;
7. observation/execution vs result vs analysis/assessment;
8. request/action vs execution status/progress vs result;
9. current state vs event/history vs broader equipment lifecycle;
10. physical subject vs logical/virtual/interface representation;
11. scoped identities and field-level provenance;
12. atomic-through-composite scale and optionality.
