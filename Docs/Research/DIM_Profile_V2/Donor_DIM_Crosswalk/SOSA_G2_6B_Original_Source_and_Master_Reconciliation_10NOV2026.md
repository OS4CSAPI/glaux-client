## 2. Source-native semantics and important negative equivalences

**Profile is hardware design, not an actual whole-system identity.** Rule 13.2.11-1 conditionally requires an ANSI/VITA 65.0 3U plug-in card (PIC) to use one of nine named slot-profile families. The source's Advanced Modular Profile Specification (AMPS) strings specify connector loading, dash selection and port/protocol allocations, not CSAPI message encoding or a field-verified System resource. Payload, switch, radial-clock, and external-I/O are scoped card/profile functions; none is a mandatory universal Domain Information Model (DIM) chassis, equipment-category enumeration or one-SOSA-Module/one-PIC identity rule.

**I/O and connectivity:** §13.2.11.1 prohibits certain inter-slot GPIO/XMC wiring, with a scoped XMC overlay exception; §13.2.11.2 defines payload aperture H/J and conditional P2A build/intermateability recommendations. §13.2.11.6 defines an external-I/O PIC, permits different control/expansion relationships in explanatory prose and prohibits user-defined inter-slot routing. These hardware possibilities do not establish a real external probe, actual manufacturer I/O cable, current IP endpoint, network member, source data producer, or a functioning CSAPI ControlStream.

**Switching and source maturity:** §§13.2.11.3–13.2.11.4 distinguish Expansion/Control from Data/Control plane switches and explicitly permit limited pipe repurposing/front-panel fiber use; a small chassis may need no expansion switch. Printed tables distinguish profile variants using source-standard date, `Ready` and legacy asterisks, which cannot be elevated to installed module inventory or current equipment availability. §13.2.11.7 introduces an RF/optical-rich aperture-K payload profile and says its architectural deployment is limited.

**Time, management and effect:** §13.2.11.5 defines hardware REF_CLK/AUX_CLK/one-pulse-per-second (1PPS) signal paths, optional Position Time Navigation (PNT), and conditional SYS_CON reassignment. These do not verify UTC, historical NOAA original event time or quality, current synchronized device clocks, or an actually executed command or acknowledgement. The nine numbered clock requirements in Table13.2.11.5-1 are references to *unread* ANSI/VITA original rule text, not independently source-verified original normative details.
