## 2. Principal source meanings established

| C239 native subject | Original locator (printed page / PDF page) | Meaning supported by the source | Incorrect shortcut expressly rejected |
| --- | --- | --- | --- |
| **System Manager 1.1 versus Task Manager 1.2** | §4.2 Table 4.2-1 p23/PDF49; §5.4 p32/PDF58 | Housekeeping (discovery, configuration, condition, state, security) versus mission requests, resource assignment and scheduling | Neither a management call nor a mission task request proves an executed physical control or completed mission |

| **System Manager decomposition** | §6.1.1 Table 6.1.1-1 pp40–42/PDF66–68 | Health, operations, configuration and security-support functions carry different monitoring and update roles | Not an obligatory DIM superclass tree or every sensor's required hardware architecture |

The C239 source distinguishes **general architectural functional descriptions** from normative standard obligations. For instance, §12.1.1 contains directly inspected numbered security-service Rules, whereas §12.11 explicitly labels Power as reference-only. This is a critical donor-review lesson: copying all Table4.2-1 entries as if they were equal-depth normative model commitments would be wrong.
