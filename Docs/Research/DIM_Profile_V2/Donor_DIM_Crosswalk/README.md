## What is being built

One horizontally organized **master spreadsheet** with individual **donor-native concepts/fields/relationships as columns** and **plain-English proposed DIM information elements as the final rightmost column**. Group divider rows organize it from identity through equipment, functions, reported data, observations, configuration, control, maintenance and provenance. A genuine concept without a defensible match gets its own row; no invented equivalence or arbitrary R24 class hierarchy. A separate source/evidence sheet underpins each populated cell, and a UML view must eventually match the actual candidate DIM register.

The historical 22-row sample is **a template**, not approval of its conceptual mappings; **Step08 instead accepts the new v0.2 case-first 13-column presentation, not any specific DIM semantics**. The complete donor roster, substantive donor ranking and updated UML are **not yet delivered**. **The working, seven-donor master XLSX has now been delivered at Step06**; it is not the final source-reviewed crosswalk. Existing legacy workbook [here](../Deliverables/DIM_V2_Donor_to_Model_Traceability.xlsx) had the **wrong primary layout** and does not replace the new master.
