# Design

Destination for wireframes, operator tasks, architecture, and profile-to-presentation
mappings. This folder adds no approved design or implementation.

The implemented UI uses the existing Overview, Equipment, and
Condition wireframes. Consult actual wireframe and profile source materials;
do not reconstruct their requirements from the brief. Keep proposed mappings
distinct from source meaning and recorded decisions.

The current simple code boundaries are described in the
[root README](../../README.md#current-implementation).
The [Details View mapping](DETAILS_VIEW_MAPPING.md) describes the initial cases;
the [power arrangement mapping](POWER_ARRANGEMENT.md) records the subsequently
authorized bounded use of the existing source A/B replacement example.
Only suitable, authorized public material may be added here.
