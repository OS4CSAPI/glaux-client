# Design

The [Artifact Register](../ARTIFACT_REGISTER.md) links the original design inputs
and records the exact current source versions. The source documents retain their
own authority and proposal boundaries.

- [Details View sources](Details_View/): Requirements v0.8, Semantic Presentation
  and Interaction Guide v0.5, and the 55-page Working Views review packet.
- [MPSS sources](MPSS/): technical profile v0.3.5, its complete connected-example
  package, and the informative pedigree/rationale primer v0.5.
- [Details View mapping](DETAILS_VIEW_MAPPING.md): bounded bindings, experimental
  device mappings, source paths, and unresolved implementation gaps.
- [Power arrangement mapping](POWER_ARRANGEMENT.md): the existing source A/B
  replacement example and its relationship/observation attribution rules.
- [Experiment page index](PAGE_INDEX.md): homepage navigation, descriptions,
  recorded update dates, and the shared catalogue to maintain as pages change.

The implementation uses the existing Overview, Equipment, and Condition views.
Its current scope does not define the whole profile's subject coverage. Consult
actual source clauses and review pages rather than inferring requirements from
the client layout or a folder name. The current code boundaries are described in
the [root README](../../README.md#current-implementation).
