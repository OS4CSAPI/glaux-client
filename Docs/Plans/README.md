# Plans

Destination for implementation plans, current status, and continuity/handoff
checkpoints. The [root README](../../README.md#current-status-and-boundaries)
is the current bootstrap status source; no detailed implementation plan is
established here.

Future plans and checkpoints should identify their date, status, evidence,
remaining work, and relationship to current decisions. A proposed plan is not
an approved change to application scope.
